# MWS Cloud Platform API

> ⚠️ API is under active development. Backward-incompatible changes may occur until the first stable release.

This repository contains the official API specifications for the MWS Cloud Platform project.
The specifications are defined using the OpenAPI 3.0 format.

The repository structure reflects the cloud platform services: each directory represents a separate service and contains its OpenAPI API specifications.
